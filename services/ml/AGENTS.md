# AGENTS.md

This repository is for the ML-models project. Keep changes focused, preserve existing files, and do not delete work already present in the project.

## Working rules
- Commit only repo-relevant files for the ML-models project.
- Keep the branch structure consistent with the project name.
- Do not overwrite existing files unless explicitly requested.
- Favor small, deliberate changes and clear documentation.
- Preserve deterministic data, reproducible configs, and test isolation.

## Project conventions
- Use the existing `src/` package layout for implementation.
- Keep YAML and JSON config files versioned and readable.
- Treat processed outputs and generated data as local artifacts.
- Prefer testable, modular components over monolithic scripts.
